## Approved Additional Features

### Style Finder / Quiz

A short guided experience that recommends products based on:
- Occasion
- Preferred style
- Preferred fit

Flow:

**Style Finder → Occasion → Style → Fit → Recommended Products → Product Details → Add to Bag**

### WhatsApp Integration

- Persistent floating WhatsApp button
- Ask about this product
- Order assistance
- Customer support
- Contact page integration

## Primary Customer Journey

**Instagram / Google / Direct → SALAM Home → Category / Collection / Occasion → Product Details → Select Color & Size → Add to Bag → Cart → Checkout → Customer Info → Address → Shipping → Payment → Order Confirmation → Preparing → Shipping Company → Shipped → Delivered**

## Payment Journeys

### Cash on Delivery

**Checkout → COD Selected → Order Created → Admin Confirmation → Preparing → Shipping → Delivered**

### InstaPay / Vodafone Cash

**Checkout → Payment Method → Transfer Instructions → Upload Payment Proof + Reference → Payment Pending Verification → Admin Approves/Rejects → Order Proceeds or Payment Rejected**

## Wishlist Journey

**Product → Add to Wishlist → Return Later → Wishlist → Product → Add to Bag**

## UX Principles

- Arabic-first and RTL, with English support planned.
- Mobile-first experience.
- Premium, calm, clear, and easy-to-use interface.
- Avoid excessive animations or complicated navigation.
- Make price, size, fabric, availability, shipping, and returns easy to understand.
- Design for confidence and trust, especially for online fashion purchases.
